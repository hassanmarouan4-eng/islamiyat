# منصة دروسي

منصة تعليمية لجميع المواد (الإعدادي والثانوي التأهيلي) تعمل برموز التفعيل: دروس وملخصات، عروض تقديمية، جذاذات، تمارين، منهجيات، فروض وامتحانات موحدة، مرتبة حسب المادة والمستوى، مع قسم للقرآن الكريم برواية ورش عن نافع والمصحف المعلم.

الملفات تُعرض داخل المنصة (PowerPoint وWord وPDF) دون نسخ. أصحاب باقات الأستاذ ينزّلون الملخصات والفروض، ويعدّلون العروض داخل المنصة فيُضاف اسمهم تلقائياً.

## النشر بنقرة واحدة

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/hassanmarouan4-eng/islamiyat)

1. اضغط الزر أعلاه وسجّل الدخول إلى Cloudflare (أو أنشئ حساباً مجانياً).
2. اربط حسابك على GitHub عندما يُطلب منك ذلك.
3. (اختياري) املأ `ADMIN_PASSWORD` و`SECRET`. إن تركتهما فارغين، تعمل المنصة بكلمة المرور الأولية ومفتاح حماية يُنشأ تلقائياً.
4. اضغط **Deploy**. بعد دقيقة يصبح رابط المنصة جاهزاً بصيغة `islamiyat.<اسمك>.workers.dev`.
5. افتح الرابط وأضف إليه `#admin`، ثم ادخل وغيّر كلمة المرور فوراً من «الإعدادات»، وأكمل خطوات الانطلاق: رقم واتساب، تغيير كلمة المرور، أول مورد، أول رموز التفعيل.

## الملفات

- `worker.js` — المنصة كاملة في ملف واحد: الواجهة والخادم ولوحة الإدارة.
- `wrangler.jsonc` — إعداد النشر ومخزن البيانات `DB`.

## حدود الخطة المجانية في Cloudflare

- مساحة تخزين إجمالية: 1 غيغابايت، وحجم الملف الواحد حتى 25 ميغابايت (للملفات الأكبر ضع رابط Google Drive).
- 1000 عملية حفظ جديدة في اليوم (كل رمز تفعيل يُولَّد عملية واحدة).
